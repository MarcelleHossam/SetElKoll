# SetelKol 🍳

**A Professional Home-Cooking Recipe Platform**
Setel Kol is a full-stack recipe platform designed to help people cook meals at home through clear, structured, step-by-step recipes.
Unlike a traditional recipe blog, Setel Kol is designed as a **digital chef's guide**, focusing on an organized and practical cooking experience.

## ✨ Features

* 🍽️ Browse recipes by category

  * Breakfast
  * Lunch
  * Dinner
  * Desserts
* 📖 View detailed recipes
* 🥕 Structured ingredient lists
* 👨‍🍳 Step-by-step cooking instructions
* ⏱️ Cooking time information
* 📊 Difficulty level
* ❤️ Save recipes for later
* ▶️ Start cooking from the recipe page
* 🛒 Recipe ordering functionality

## 🧑‍🍳 How It Works
1. Open the SetelKol website.
2. Browse available dishes by category.
3. Select a recipe.
4. View the ingredients and cooking information.
5. Follow the step-by-step cooking instructions.
6. Save a recipe for later or start cooking.
7. Use the ordering functionality when available.


## 🎯 Project Goal
The goal of SetelKol is to provide a more practical alternative to traditional recipe websites by presenting recipes as structured cooking guides.
The platform focuses on making it easy for users to discover dishes, understand what they need, and follow the cooking process step by step.
